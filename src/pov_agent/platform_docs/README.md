# Platform docs corpus (demo)

A small set of illustrative docs for **Nimbus AI Platform**, a fictional private AI
platform: an on-prem GPU cluster with a data-science workbench, model serving, and a
catalog of ML tools. The agent searches these files with its `search_platform_docs` /
`read_platform_doc` tools, so answers are grounded and the eval is deterministic and
reproducible in CI (no live web calls).

Replace these files with an export of the docs your team actually uses. Drop more `.md`
files in this folder and the search tool picks them up automatically. Each file's first
`# ` heading is its title, and `## ` headings split it into searchable sections.

This README is not indexed.
